## Change summary

- **`scs bundle diff [BUNDLE] [--from V] [--to V|working]`** is new. It shows what changed in a
  bundle between two versions, or between a version and the working tree, across the bundle's
  whole tree: SCDs added and removed; prohibitions, directives, and facts added, removed, and
  changed (with the fields that changed); citations added and removed, on the SCD or an item;
  and imports added, removed, and re-pinned. It writes nothing. With `--json` the structured
  diff is in `result`; every list is sorted, so the same inputs give the same bytes.
- **Defaults.** BUNDLE defaults to the workspace's root bundle, `--to` to `working`, and
  `--from` to the bundle's latest version. A version's content comes from its tag and must pass
  the tag's integrity check (`CONTENT_DIGEST_MISMATCH` otherwise). A `--from` or `--to` version
  with no tag is `DIFF_VERSION_NOT_FOUND`.
- **No version yet.** A bundle with no version diffs from empty: everything is added. A bundle
  whose only versions are pre-0.7 diffs from its latest `<file stem>-v<version>.yaml` snapshot,
  with `DIFF_LEGACY_BASELINE` (info). That snapshot holds the bundle file only, so SCDs present
  on both sides are listed under `not_compared` rather than item by item.
