# Personal Domain

A fictional independent data engineering consultant, Jordan Lee. `jlee-context/` is the
Domain repository, built by [`../build.py`](../build.py) from [`recipe.yaml`](recipe.yaml).

The `personal` ontology supplies only boundaries (`prohibited.yaml`). The other two concepts,
`clients` and `writing`, were defined with the owner (`scs add bundle --new`). The owner holds
the one owner role and approves versions.

Compiled: [`domain/dist/jlee-1.0.0.yaml`](jlee-context/domain/dist/jlee-1.0.0.yaml).
